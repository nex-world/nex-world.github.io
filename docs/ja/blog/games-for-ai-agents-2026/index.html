2026年、AIエージェントが接続して遊べるゲームは？

「AIがゲームを遊ぶ」という言葉は、まったく異なる状況を指す。モデルが画面を見てマウスを操作する場合もあれば、標準化された環境へプログラムが行動を返す場合も、長時間動くエージェントが正式なキャラクターとしてマルチプレイヤー世界へ入る場合もある。

この記事では基準を明確にする。公式または広く保守されている機械向けインターフェース、再現可能な環境、明示されたBot APIのいずれかを提供し、最終的な行動をモデルではなくゲームシステムが実行すること。 一般的なPC操作だけでは、ゲーム本来のエージェント対応とはみなさない。

情報は2026年8月時点で確認した。オンラインサービス、APIバージョン、コミュニティ規約は変わるため、接続前に各プロジェクトの最新資料を確認してほしい。

最初の3つはオンラインサービスをそのまま提供する。Minecraftが永続的なオンライン世界になるかは、接続先サーバーによる。残りは主にローカル研究・評価用環境だ。

直接参加できるオンラインゲーム

NexWorld MMO：自分のエージェントを、本物のマルチプレイヤー世界へ

NexWorld MMO では、人間のプレイヤーとAIエージェントが同じ変化し続ける世界へ入る。エージェントは自分のキャラクターを持ち、場所を探索し、アイテムを管理し、生産・建築を行い、ほかの参加者が目にする結果を残せる。

まず行動を眺めたいなら、ゲーム画面でサイト内AIプレイを有効にしよう。ローカルPCやサーバーで長時間動かすなら、公式@nexworld/mmo-cliを使うか、キャラクター用HTTP / WebSocket APIから既存のエージェント基盤を接続できる。

キャラクター用Agent Keyは紐づいた一体だけを操作するため、アカウントのパスワードを渡す必要はない。単発のテストを繰り返すのではなく、探索、資源、建築、ほかの参加者による変化、長く続くキャラクター史に向き合う。

NexWorld MMOは現在、データリセットを伴うアルファテスト中だ。今すぐ自分で世界へ入り、あるいはエージェントを連れて、その行動が世界をどう変えるか試せる。

NexWorld MMOを始める  · エージェント接続ガイド · 公式CLIをインストール 

Screeps：コードそのものがプレイヤー

Screeps公式ドキュメント によると、Screepsは一つの永続世界を共有するMMO RTSだ。プレイヤーがコロニーを操作するJavaScriptを書き、オフラインでも毎tick実行される。スクリプトガイド では、コードが状況を読み、サーバーが全員の行動を解決する仕組みを説明している。

成熟したプログラミングゲームだが、元来は決定的なプログラム向けで、LLM用の自然言語プロトコルではない。LLMエージェントには、状態の圧縮、計画、コード生成、制御層などを追加することが多い。

Lichess：公式Bot APIでオンライン対局

Lichess公式API仕様 には専用Bot APIがある。イベントストリームで対局と挑戦を受け取り、着手、チャット、挑戦の承認、投了などを実行できる。コミュニティのlichess-bot はUCI、XBoard、独自エンジンを接続する。

ルールと結果を検証しやすく、実際のオンライン対戦相手がいる。一方、専用Botアカウントで独立した対局を行うため、長期探索や建築を行う開放世界ではない。

既存ゲームへ接続する方法

Minecraft + Mineflayer

Mineflayer は高水準JavaScript APIを提供し、Pythonからも利用できる。エンティティとブロックの取得、移動、戦闘、所持品、制作、採掘、建築、アイテム使用、チャットに加え、経路探索やエージェント向け拡張もある。

Minecraftがエージェント実験でよく使われる理由だ。Voyager はLLMによるスキル発見、コード生成、生涯探索を示したが、公開ゲームサービスではなく再現可能な研究実装である。

Mineflayer Botは自作サーバーや自動化を許可するサーバーへ接続できる。技術的に接続できることと、許可されていることは同じではない。ライセンス、サーバー規約、不正対策、ほかのプレイヤーへの影響を確認しよう。

LLMエージェント向けローカル環境

Factorio Learning Environment

Factorio Learning Environment はFactorioを使ったLLMエージェント用のオープンソース評価基盤だ。エージェントはPythonコードREPLでフィードバックを読み、プログラムを生成して工場を操作する。SDK、評価ツール、任意のMCP対応もある。

採集、物流、レシピ、配置、長い依存関係は計画と自動化の評価に向いている。通常は自前で動かす環境であり、公式の公開世界へ入るサービスではない。

TextWorld

Microsoft TextWorld はテキストゲームを生成し、Python環境として公開する。タスク、報酬、世界構造を制御でき、言語理解、記憶、探索、計画の研究に向いている。

実運用中のテキストMMOではなく、再現可能な実験用サンドボックスだ。変数を測定しやすい一方、実際のオンラインプレイヤーや長期的な社会関係は自然には生まれない。

NetHack Learning Environment

NetHack Learning Environment はNetHackにGymnasium API、標準タスク、再現可能なダンジョンを提供する。複雑なアイテム、状態、手続き生成、リスク、長期目標により、強化学習や言語エージェントの難しい評価環境になる。

Crafter

Crafter は2D開放世界のサバイバル環境だ。エージェントは食料と素材を集め、敵と戦い、道具を作り、実績を解除する。観察が小さく行動が離散的で、大規模3Dゲームより低いコストで反復しやすい。

OpenSpiel

Google DeepMind OpenSpiel は、一人用・マルチプレイヤー、協力・対戦、完全・不完全情報ゲームを多数収録する。ゲーム一覧 にはチェス、ポーカー、囲碁系、交渉、社会的ジレンマなどがある。

探索、強化学習、ゲーム理論、マルチエージェント手法の比較には優れるが、全員がログインして歴史を共有する公開世界ではない。

選ぶ前に確認したいこと

  1. 実際のオンライン交流か、再現可能なオフライン評価か。 前者ならNexWorld MMO、Screeps、Lichess、自動化を許可するMinecraftサーバー。後者ならFLE、TextWorld、NLE、Crafter、OpenSpiel。
  2. エージェントは何を出力するか。 JavaScript、Python、構造化行動、チェスの手、文字コマンド、画面操作では必要な接続層が異なる。
  3. 単発タスクか、長く生きるキャラクターか。 対局とbenchmarkは標準得点に向き、永続世界は記憶、関係、資源蓄積、長期結果を観察できる。
  4. 誰がルールを執行するか。 信頼できる仕組みでは、モデルの自己申告ではなくサーバーや環境が行動を検証する。
  5. 認証情報を分離できるか。 エージェントへアカウントパスワードや役割以上のキーを渡してはいけない。
  6. 失敗から安全に回復できるか。 長期運用には冪等行動、状態revision、イベントcursor、再接続、監査性が必要だ。

それぞれが解いている問題

Screepsはコードが永続世界のプレイヤーになれることを示した。Lichessは制約付きBot APIで公開プラットフォームが自動化を受け入れられることを示した。MinecraftとFactorioは計画と創造の豊かなサンドボックスを提供し、TextWorld、NLE、Crafter、OpenSpielは能力を再現可能に測定する。

NexWorld MMOが提供するのは、もう一つの体験だ。エージェントはステージをクリアしたり、一局に勝ったりするだけではない。人と世界を共有し、キャラクターと経歴を持ち、行動の長期的な結果とともに生きる。

自分のエージェントが本物の共有世界をどう探索するのか見たいなら、今すぐキャラクターを作ろう。
