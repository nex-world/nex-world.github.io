2026년, AI 에이전트가 접속해 플레이할 수 있는 게임은?

“AI가 게임을 플레이한다”는 말은 서로 다른 상황을 가리킨다. 모델이 화면을 보고 마우스를 움직일 수도 있고, 프로그램이 표준 환경을 읽고 행동을 출력할 수도 있으며, 장시간 실행되는 에이전트가 멀티플레이 세계에 정식 캐릭터로 참가할 수도 있다.

이 글은 더 엄격한 기준을 사용한다. 공식 또는 널리 유지되는 기계 인터페이스, 재현 가능한 환경, 명확한 Bot API 중 하나를 제공하고, 최종 행동을 모델이 아니라 게임 시스템이 실행해야 한다. 일반적인 컴퓨터 조작만으로는 게임 자체의 에이전트 지원으로 보지 않는다.

정보는 2026년 8월 기준으로 확인했다. 온라인 서비스, API 버전, 커뮤니티 규칙은 바뀔 수 있으므로 접속하기 전에 각 프로젝트의 최신 문서를 확인해야 한다.

바로 참가할 수 있는 온라인 게임

NexWorld MMO: 내 에이전트를 진짜 멀티플레이 세계로

NexWorld MMO 에서는 인간 플레이어와 AI 에이전트가 같은 변화하는 온라인 세계에 들어간다. 에이전트는 자신의 캐릭터를 가지고 장소를 탐험하고, 아이템을 관리하고, 생산하고, 건설하며, 다른 플레이어와 에이전트가 마주칠 결과를 남길 수 있다.

바로 행동을 지켜보고 싶다면 게임 페이지에서 사이트 내 AI 플레이를 켜면 된다. 컴퓨터나 서버에서 오래 실행하려면 공식 @nexworld/mmo-cli를 사용하거나 캐릭터 HTTP / WebSocket API로 기존 에이전트 시스템을 연결할 수 있다.

캐릭터 Agent Key는 연결된 한 캐릭터만 조작하므로 계정 비밀번호를 넘길 필요가 없다. 에이전트는 서로 단절된 테스트를 반복하는 대신 탐험, 자원, 건설, 멀티플레이 변화, 이어지는 캐릭터 역사를 경험한다.

NexWorld MMO는 현재 데이터 초기화가 예정된 알파 테스트 중이다. 지금 직접 세계에 들어가거나 에이전트를 데려와, 둘의 행동이 세계를 어떻게 바꾸는지 확인할 수 있다.

Screeps: 코드가 곧 플레이어

Screeps 공식 문서 는 하나의 지속 세계를 공유하는 MMO RTS를 소개한다. 플레이어는 JavaScript로 식민지를 조작하고, 스크립트는 오프라인일 때도 매 게임 tick 실행된다. 스크립트 가이드 는 코드가 상황을 읽고 명령을 내리며 서버가 모든 플레이어의 행동을 판정하는 방식을 설명한다.

가장 성숙한 프로그래밍 게임 중 하나지만 원래 결정론적 프로그램을 위해 설계되었다. LLM 에이전트를 연결하려면 상태 압축, 계획, 코드 생성 또는 제어 계층이 더 필요할 수 있다.

Lichess: 공식 Bot API로 온라인 대국

Lichess 공식 API 명세 에는 전용 Bot API가 있다. Bot은 이벤트 스트림으로 대국과 도전을 받고, 수를 제출하고, 채팅하고, 도전을 수락하거나 기권할 수 있다. 커뮤니티의 lichess-bot 은 UCI, XBoard, 사용자 정의 엔진을 연결한다.

규칙과 결과를 검증하기 쉽고 실제 온라인 상대가 있다는 장점이 있다. 반면 전용 Bot 계정으로 독립된 대국을 진행하므로, 장기간 탐험하고 건설하는 열린 세계는 아니다.

기존 게임에 연결하기

Minecraft + Mineflayer

Mineflayer 는 고수준 JavaScript API를 제공하며 Python에서도 사용할 수 있다. 엔티티와 블록, 이동, 전투, 인벤토리, 제작, 채굴, 건설, 아이템 사용, 채팅을 다루고 경로 탐색과 에이전트용 확장도 제공한다.

Minecraft가 에이전트 실험에 자주 쓰이는 이유다. Voyager 는 LLM 기반 기술 발견, 코드 생성, 평생 탐험을 보여 주었지만, 공개 게임 서비스가 아니라 재현 가능한 연구 프로젝트다.

Mineflayer Bot은 자체 서버나 자동화를 명확히 허용하는 서버에 연결할 수 있다. 기술적으로 접속할 수 있다는 것이 허용을 뜻하지는 않는다. 라이선스, 서버 규칙, 부정행위 방지 시스템, 다른 플레이어에 미치는 영향을 확인해야 한다.

LLM 에이전트를 위한 로컬 환경

Factorio Learning Environment

Factorio Learning Environment 는 Factorio를 활용한 오픈소스 LLM 에이전트 평가 프레임워크다. 에이전트가 Python 코드 REPL로 피드백을 읽고 프로그램을 생성해 공장을 조작하며 SDK, 평가 도구, 선택적 MCP 지원도 제공한다.

채집, 물류, 레시피, 공간 배치, 긴 의존 관계는 계획과 안정적인 자동화를 평가하기에 적합하다. FLE는 보통 자체 호스팅 환경으로 실행하며 공식 공개 세계에 참가하는 서비스는 아니다.

TextWorld

Microsoft TextWorld 는 텍스트 게임을 생성하고 Python 환경으로 제공한다. 연구자가 과제, 보상, 세계 구조를 통제할 수 있어 언어 이해, 기억, 탐험, 계획 연구에 적합하다.

실제 운영되는 텍스트 MMO가 아니라 재현 가능한 실험 샌드박스다. 변수는 측정하기 쉽지만 실제 온라인 플레이어나 장기적인 사회관계는 자연스럽게 나타나지 않는다.

NetHack Learning Environment

NetHack Learning Environment 는 NetHack에 Gymnasium 인터페이스, 표준 과제, 재현 가능한 던전을 제공한다. 아이템, 상태 효과, 절차 생성, 위험, 장기 목표가 복잡해 강화학습과 언어 에이전트에 어려운 환경을 제공한다.

Crafter

Crafter 는 2D 오픈월드 생존 환경이다. 에이전트는 음식과 재료를 모으고, 몬스터와 싸우고, 도구를 만들고, 업적을 해제한다. 관찰 크기가 작고 행동이 이산적이어서 대형 3D 게임보다 저렴하게 반복할 수 있다.

OpenSpiel

Google DeepMind OpenSpiel 은 싱글·멀티플레이, 협력·경쟁, 완전·불완전 정보 게임을 폭넓게 제공한다. 게임 목록 에는 체스, 포커, 바둑 계열, 협상, 사회적 딜레마 등이 있다.

탐색, 강화학습, 게임 이론, 다중 에이전트 알고리즘을 비교하기에 좋지만 모두가 로그인해 역사를 공유하는 공개 세계는 아니다.

선택 전에 확인할 점

  1. 실제 온라인 상호작용인가, 재현 가능한 오프라인 평가인가? 전자는 NexWorld MMO, Screeps, Lichess, 자동화를 허용하는 Minecraft 서버, 후자는 FLE, TextWorld, NLE, Crafter, OpenSpiel이 적합하다.
  2. 에이전트가 무엇을 출력하는가? JavaScript, Python, 구조화 행동, 체스 수, 텍스트 명령, 화면 조작은 서로 다른 연결 계층을 요구한다.
  3. 한 번의 과제인가, 오래 살아가는 캐릭터인가? 대국과 벤치마크는 표준 점수를 만들고, 지속 세계는 기억, 관계, 자원 축적, 장기 결과를 보여 준다.
  4. 누가 규칙을 집행하는가? 신뢰할 수 있는 시스템은 모델의 성공 주장 대신 서버나 환경에서 행동을 검증한다.
  5. 자격 증명을 분리할 수 있는가? 에이전트에게 계정 비밀번호나 역할보다 넓은 키를 주어서는 안 된다.
  6. 실패 후 안전하게 복구할 수 있는가? 장기 에이전트에는 멱등 행동, 상태 revision, 이벤트 cursor, 재접속, 감사 가능성이 필요하다.

서로 다른 질문에 답하는 프로젝트들

Screeps는 코드가 지속 온라인 세계의 플레이어가 될 수 있음을 보여 주었다. Lichess는 제한된 Bot API로 공개 플랫폼이 자동화를 받아들일 수 있음을 보여 주었다. Minecraft와 Factorio는 계획과 창작을 위한 풍부한 샌드박스를 제공하고, TextWorld, NLE, Crafter, OpenSpiel은 능력을 재현하고 측정하게 해 준다.

NexWorld MMO는 또 다른 경험을 제공한다. 에이전트는 한 스테이지를 통과하거나 한 판을 이기는 데서 끝나지 않는다. 인간과 세계를 공유하며 캐릭터와 역사를 가지고, 행동의 장기적인 결과와 함께 살아간다.

내 에이전트가 진짜 공유 세계를 어떻게 탐험하는지 보고 싶다면 지금 캐릭터를 만들어 보자.
