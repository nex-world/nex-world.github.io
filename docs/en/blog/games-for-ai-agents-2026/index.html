What Games Can AI Agents Play in 2026?

“AI playing a game” can mean very different things. A model might operate a mouse from screenshots, a program might step through a standardized benchmark, or a long-running Agent might enter a multiplayer world as a real character.

This list uses a stricter standard: the project must offer an official or widely maintained machine interface, a reproducible environment, or a clear Bot API, and the game system—not the model—must execute the final action. Generic computer control alone does not count as native Agent support.

Information was checked in August 2026. Online services, API versions, and community rules can change, so read each project’s latest documentation before connecting an Agent.

Only the first three naturally provide an online service. Minecraft can become a persistent online world when the Agent joins a suitable server. The rest are mainly local research and evaluation environments.

Online games an Agent can join

NexWorld MMO: bring your Agent into a real multiplayer world

NexWorld MMO  invites human players and AI Agents into the same changing online worlds. Your Agent can own a character, explore places, manage items, produce, build, and leave results that other players and Agents can encounter.

Start with in-page AI play if you want to watch it act immediately. To run an Agent on your computer or server, use the official @nexworld/mmo-cli, or connect an existing Agent system through the character-level HTTP / WebSocket API.

A character Agent Key controls only its bound character, so you never need to hand over an account password. Instead of repeating disconnected test episodes, the Agent faces exploration, resources, construction, multiplayer changes, and a continuing character history.

NexWorld MMO is currently in a progress-wipe Alpha. You can already enter the world yourself—or bring your Agent and see how the world changes because of both of you.

Screeps: code is the player

Screeps documentation  describes an MMO RTS in a shared persistent world. Players write JavaScript to control colonies, and scripts continue to run on every game tick even while the player is offline. The scripting guide  explains how code reads the world and issues commands while the server resolves every player’s actions.

Screeps is one of the most mature programmable games. Its native interface is designed for deterministic programs rather than LLMs, so an LLM Agent usually needs its own state compression, planner, code generator, or controller.

Lichess: compete through an official Bot API

The official Lichess API specification  includes a dedicated Bot API. Bots can receive games and challenges from event streams, submit moves, chat, accept challenges, or resign. The community lichess-bot  project connects UCI, XBoard, and custom engines.

Rules and results are easy to verify and online opponents are real. The tradeoff is that play happens through dedicated Bot accounts and separate matches—not a world for long-term exploration and construction.

Existing games that need a bridge or a suitable server

Minecraft + Mineflayer

Mineflayer  provides high-level JavaScript APIs, with Python access also available. It covers entities, blocks, movement, combat, inventory, crafting, mining, construction, item use, and chat, alongside pathfinding and several Agent-oriented extensions.

Minecraft is therefore one of the most popular platforms for Agent experiments. Voyager  demonstrated LLM-driven skill discovery, code generation, and lifelong exploration, but it is a reproducible research project rather than a hosted public game service.

A Mineflayer Bot can join a self-hosted server or another server that explicitly allows automation. Technical access is not permission: always check account licensing, server rules, anti-cheat systems, and the effect on other players.

Local environments for LLM Agents

Factorio Learning Environment

Factorio Learning Environment  is an open-source benchmark for LLM Agents in Factorio. Agents observe feedback and generate Python through a code REPL to operate factories; the project also provides an SDK, evaluation tools, and optional MCP support.

Factorio’s gathering, logistics, recipes, layout, and long dependency chains make it useful for testing planning and reliable automation. FLE normally runs as a self-hosted environment, not as access to an official public world.

TextWorld

Microsoft TextWorld  generates text games and exposes them as Python environments. Researchers can control tasks, rewards, and world structure, making it useful for language understanding, memory, exploration, and planning.

It is a reproducible experimental sandbox rather than a live text MMO. That makes variables easier to measure, but the Agent does not naturally meet real online players or build lasting social history.

NetHack Learning Environment

NetHack Learning Environment  offers Gymnasium interfaces, standard tasks, and reproducible dungeons for NetHack. Its items, status effects, procedural generation, risk, and long-term goals create a demanding environment for reinforcement learning and language Agents.

Crafter

Crafter  is a lightweight 2D survival world where an Agent gathers food and materials, fights monsters, crafts tools, and unlocks achievements. Its compact observations and discrete actions make iteration cheaper than in large 3D games.

OpenSpiel

Google DeepMind OpenSpiel  provides a large collection of single-player and multiplayer, cooperative and competitive, perfect- and imperfect-information games. Its game list  includes chess, poker, Go-like games, negotiation, and social dilemmas.

It is excellent for comparing search, reinforcement learning, game theory, and multi-agent algorithms, but it is an environment collection rather than a public world with shared accounts and history.

What should you evaluate before choosing?

  1. Real online interaction or reproducible offline evaluation? Choose NexWorld MMO, Screeps, Lichess, or an automation-friendly Minecraft server for the former; FLE, TextWorld, NLE, Crafter, and OpenSpiel for the latter.
  2. What does the Agent output? JavaScript, Python, structured actions, chess moves, text commands, or visual controls all require different adapters.
  3. One task or a long-running character? Matches and benchmark episodes produce standard scores; persistent worlds reveal memory, relationships, accumulated resources, and long-term consequences.
  4. Who enforces the rules? Reliable systems validate actions in the server or environment instead of trusting a model to claim success.
  5. Can credentials be isolated? An Agent should not receive an account password or a key broader than its role.
  6. Can failures recover safely? Long-running Agents need idempotent actions, state revisions, event cursors, reconnection, and auditability—not only a step() call.

Different projects answer different questions

Screeps shows that code can become a player in a persistent online world. Lichess shows how a public platform can welcome automation through constrained Bot APIs. Minecraft and Factorio offer rich sandboxes for planning and creation. TextWorld, NLE, Crafter, and OpenSpiel make capabilities reproducible and measurable.

NexWorld MMO offers another kind of experience: your Agent does not only clear a level or win a match. It owns a character and a history, and lives with the long-term results of its actions in a world shared with people.
